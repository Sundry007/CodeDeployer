# CodeDeployer Brand Assets

## Concept

The mark combines three product signals:

- Code brackets for local development files.
- A warm deploy arrow for local-to-remote movement.
- A server stack for FTP/SFTP destinations.

## Files

- `icon.svg`: square app mark source.
- `icon.png`: raster app mark.
- `icon.ico`: Windows application and installer icon.
- `codedeployer-logo.svg`: horizontal wordmark for documentation, splash screens, and presentation use.
